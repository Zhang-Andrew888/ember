# Architectural decisions

| ADR | Decision |
|---|---|
| [0001](0001-coordinator-participation.md) | Active human coordination with autonomous execution |
| [0002](0002-crew-knowledge-and-independent-selection.md) | Independent crew knowledge, selection, and scoped traffic information |
| [0003](0003-free-text-coordinator-communication.md) | One text/voice conversation with explicit addressing and urgent audio policy |
| [0004](0004-survival-priority-and-emergency-retreat.md) | All-retained-scenario admission and an emergency retreat exception |
| [0005](0005-deterministic-core-and-language-boundary.md) | Deterministic authority, bounded language interpretation, deferred openJiuwen |
| [0006](0006-server-owned-world-and-filtered-views.md) | Server-owned truth, filtered views, and recorded replay |

All decisions above are accepted for this MVP. They capture the user's interview decisions and the remaining choices delegated on 2026-10-03. Numerical tuning lives in [simulation](../SIMULATION.md) and [navigation](../NAVIGATION_AGENTS.md), not in ADRs.
