# Make coordinator participation part of the simulation

Ember Line is an active simulation in which the human incident coordinator intervenes using a broader but incomplete picture assembled from crew and scout observations. Routine execution does not require approval. A purely autonomous showcase would omit the intended experience; constant step approval would prevent agents from showing initiative.

Crews independently select and execute missions. Feasible coordinator objectives take precedence, but crews choose routes and timing and reject infeasible objectives with reasons. Withdrawal and best-effort retreat begin automatically. Targeted information updates can improve an agent's knowledge as well as its objective.

Communication uses one free-text and push-to-talk conversation addressing one agent at a time. The incident continues during communication and clarification. Map interactions support inspection rather than command entry. Mission changes use actual positions, timed reservations, and physical reversal as specified in [navigation](../NAVIGATION_AGENTS.md).
