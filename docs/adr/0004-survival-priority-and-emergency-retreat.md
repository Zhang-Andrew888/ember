# Prioritize crew survival and allow emergency retreat

Normal missions must pass approach, work, and return checks in every retained forecast scenario with a time buffer. Task value and coordinator authority cannot compensate for a failed check. This replaces quantile-only admission and accepts reduced work output to preserve modeled return feasibility across all retained futures.

These are conditional model checks, not guarantees. An ensemble contradicted by observations is marked unreliable and rebuilt with broader hypotheses from that decision-maker's evidence. Empty or unsupported ensembles cannot admit protection work. See [navigation](../NAVIGATION_AGENTS.md) for the buffer, retention, rebuild, and search defaults.

If continuing work fails but immediate return passes, the crew withdraws automatically. If no normal return passes, it stops work and attempts the lowest-estimated-exposure retreat among known passable alternatives, reporting uncertainty urgently. This exception permits emergency escape, not beginning or continuing infeasible protection work. Record return-plan failure separately from eventual return or loss.

Actual fire contact can permanently remove a crew. The incident continues until a documented end condition; losing all protection crews ends it even if the scout survives. All sites being resolved also ends it immediately without a mandatory return phase. Preserve actual agent and site outcomes at that instant; neither an unfinished return nor a destroyed site is a success. [Simulation rules](../SIMULATION.md).
