# Keep truth on the server and publish scoped views

The authoritative server owns the hidden fire, all physical outcomes, and the incident clock. Browser and agent consumers receive explicit projections for their roles. The Three.js frontend never receives the complete active fire and then attempts to conceal it with rendering effects.

This adds serialization and worker boundaries compared with an all-client simulation, but makes the incomplete-information experience enforceable and prevents accidental shared-state access from undermining coordinator intervention. A forecast cache may be shared only for identical scoped inputs.

Record applied commands, interpretation results, ordered events, and scenario versions for replay. Replays use recorded outputs rather than new model calls; active-run clients cannot request hidden replay data. See [architecture](../ARCHITECTURE.md) and [validation](../VALIDATION.md).
